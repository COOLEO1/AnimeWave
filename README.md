# AnimeWave 🌌

AnimeWave is a native Android anime discovery app built with Kotlin and Jetpack Compose. It uses a cinematic dark interface inspired by the browsing patterns in CineWave: a featured artwork hero, horizontal poster carousels, title details, search, saved titles, and bottom navigation.

## Connected features

- Live trending anime catalog and text search from the public Kitsu API
- Poster and cover artwork loaded over HTTPS with Coil
- Anime synopsis, year, subtype, ratings and known episode counts
- Episode metadata when Kitsu has a listing
- Saved titles for the current app session
- CartoonsArea website button for manual source testing in the browser
- Loading, retry and empty states
- GitHub Actions debug APK artifact

## Important source distinction

Kitsu provides catalog metadata and artwork; it does **not** provide playable video streams. The CartoonsArea button opens the website in an external browser. It does not scrape the website, bypass DRM or access controls, extract protected media, or download videos. In-app playback and downloads need a verified, authorized direct media source and its applicable permissions.

## Build an APK

1. Open the [Actions tab](https://github.com/COOLEO1/AnimeWave/actions).
2. Select **Build AnimeWave Android APK** or wait for a push-triggered run.
3. Open a successful run and download the `AnimeWave-debug-apk` artifact.

## Stack

- Kotlin + Jetpack Compose
- Kitsu JSON:API for anime metadata and episode listings
- Coil for image loading
- Gradle + GitHub Actions

## Data and network

The app needs internet access for the catalog and artwork. Catalog results and episode availability depend on Kitsu's API and may change or be incomplete. Kitsu metadata and artwork are credited to Kitsu.

## Local build

Requires JDK 17 and Android SDK platform 35. Run `gradle assembleDebug` after installing Gradle, or use the Gradle wrapper generated by Android Studio.


## Nyaa source (experimental)

AnimeWave includes a native Nyaa RSS search screen for release metadata (title, size, seeders/leechers and date when exposed by the feed). Nyaa is an index; AnimeWave does not host the indexed media. Selecting a release opens a compatible external app with a magnet URI when the feed provides a valid info hash, otherwise it opens the release page. A torrent client is required for magnet downloads; Android DownloadManager does not handle BitTorrent. Use only content you are authorized to download.

RSS fields can change or be unavailable. If Nyaa does not return an info hash in its RSS feed, the app intentionally falls back to the release page instead of inventing a magnet link.
