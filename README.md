# AnimeWave 🌌

A native Android anime-discovery app starter built with Kotlin and Jetpack Compose. The initial build provides a premium dark-purple UI and a replaceable catalog-provider interface.

## Current status

- Native Android app UI (Home, Discover, Downloads, Library)
- Search field and sample catalog entries for layout preview
- Replaceable `AnimeSource` interface for a licensed catalog provider
- GitHub Actions workflow builds a debug APK and uploads it as an artifact

**Important:** Sample titles and artwork are demo placeholders. No third-party catalog or streaming source is connected yet. Connect only a source you own or are authorized to use. This starter does not bypass DRM, access controls, or provider restrictions.

## Build an APK

1. Open the **Actions** tab in this repository.
2. Select **Build AnimeWave Android APK** and run the workflow (or push a commit).
3. Open the completed workflow run and download the `AnimeWave-debug-apk` artifact.

## Local build

Requires JDK 17 and Android SDK platform 35. Run `gradle assembleDebug` after installing Gradle, or use the Gradle wrapper generated by Android Studio.

## Storage

The starter includes a download-destination model for app-private storage and public Downloads. Actual media downloading is intentionally not implemented until an authorized source and its download rules are established.
